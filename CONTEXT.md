# Git Gud

Git Gud is an account-free desktop client for understanding and operating local Git repositories.

## Language

**Everyday Local Git Workflow**:
The repository work a developer performs routinely on their own machine: inspect history and changes, stage and commit work, manage branches and remotes, synchronize with remotes, resolve conflicts, stash work, tag history, and recover from mistakes.
_Avoid_: Full GitKraken parity, GitKraken replacement

**Default Sync Operation**:
The fetch or pull strategy invoked by the primary repository synchronization control.
_Avoid_: Default pull/fetch operation

**Partial Stash**:
A stash containing changes from selected files rather than every change in the working directory.
_Avoid_: Staged stash, hunk stash

**Ignored Change**:
An untracked path intentionally excluded from Git status by a repository-owned ignore rule.
_Avoid_: Discarded change, deleted change
